# Test Case: TC-WL-002

## Description
Verify system behavior when a guest user attempts to add a product to the Wishlist.

## Pre-conditions
- The user is not logged in (Guest state)  
- The website is up and running normally  

## Steps
1. Navigate to homepage without logging in  
2. Go to the product listing page  
3. Select any product  
4. Click on the heart icon (♡) or "Add to Wish List" button  

## Test Data
- No account required  
- Product: MacBook  

## Expected Result
- The system redirects to Login page OR displays a login popup  
- The product is NOT added to Wishlist  

## Actual Result
- displays a login popup  
- The product is NOT added to Wishlist 
## Status
Pass 

## Priority
High  

## Severity
Major
